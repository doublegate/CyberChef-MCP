## Intent

Close the gap between what this project's gates appear to check and what they check.

## Candidate scope

**Tool metadata integrity.** Tool descriptions reach the model from `src/core/config/OperationConfig.json`,
which is mirrored from upstream on every sync. That is a path from an upstream commit to text a
model reads as instruction. Measured across all 504 operations today:

```text
Unicode TAG-block characters   0
control characters             0
bidi override characters       0
non-ASCII (benign, accents)   27
```

No defect — and no guard. A cheap assertion in the sync path would make an upstream change that
introduced concealed metadata fail loudly rather than ship.

**Restore the Trivy gate.** `security-scan.yml` gates on CRITICAL only, carrying
`TODO(PR 7): restore ... once the backlog is zero`, whose stated reason is *"a 272-finding backlog"*.
That backlog is **now zero** (0 Dependabot, 0 code-scanning), so the precondition is already met and
the narrowed gate is simply outliving its cause.

**Make benchmarks able to fail.** `performance-benchmarks.yml` states in its own output that it
*"cannot fail on a regression"*. Honest, and it means the cold-start and throughput numbers this
project fought for are unprotected.

## Triggers

- An upstream sync lands an operation whose metadata is not plain printable text.
- Any of the three gates above is cited as evidence in a release note. A gate used as evidence must
  actually gate.
