# Charter: v4.2.0 — `ext-proj-int`, phase 1

> Run [`../../v3/RE-MEASURE.md`](../../v3/RE-MEASURE.md) first.

## Intent

The genuine feature backlog. `docs/planning/ext-proj-int/` scopes **80-120 tools drawn from 8
reference projects**; roughly four shipped in v2.4.0 and fourteen more arrived through v3.8.0 as
registry tools. This charter takes the next coherent slice.

## What qualifies, and what does not

The bar is already written and has held for nineteen tools. A registry tool must fill one of three
gaps an operation cannot:

1. a **loop with a decision inside it** (the cipher solvers);
2. a statistic computed **across inputs** (`corpus_diff`, `rsa_multi_key`, `hash_statistics`,
   `ecdsa_recover`, `cert_chain`);
3. a cipher upstream simply lacks (`classical_cipher`).

Anything expressible as `run(input, args)` over one input is an **operation**, and belongs upstream
or nowhere — `src/core/**` is mirrored, so a fork-local operation becomes a `patches/fork` patch
that must keep applying forever.

## Candidate scope

Selection is deliberately deferred to the RE-MEASURE pass, because the last four releases each found
a candidate already covered by an existing operation. Start by re-checking the ext-proj-int list
against the live 504 rather than against its own notes.

## Licence gate, which is not optional

The GPL-3.0-or-later relicense in v2.0.0 unblocked katana (GPLv3-or-later) and John the Ripper.
**Any borrowed algorithm must have its licence recorded in `THIRD-PARTY-NOTICES.md` in the same
change**, and that file is checked by `registry-tool-docs.test.mjs` — it is exempt from the
inventory rule *because* it is keyed by borrowed work rather than by tool.

## Trigger

None needed; the backlog exists. Sequenced after v4.1.0 only because the entry-point work makes
tool tests cheaper to write.

## Kill criteria

- A candidate an existing operation already covers. Check `cyberchef_search` and the 504 first.
- A candidate that needs network access — `CYBERCHEF_OFFLINE` guards the recipe, and a registry tool
  that reaches the network sidesteps that guard entirely.
- A candidate requiring a dependency larger than the tool. `@jimp` at 89 MB and `tesseract.js-core`
  at 44 MB are already why `<50 MB` is unreachable for the image.
