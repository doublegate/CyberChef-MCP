# Charter: v4.5.0 — Tool result contracts

> Run [`../../v3/RE-MEASURE.md`](../../v3/RE-MEASURE.md) first.

## Intent

The MCP roadmap's "Improved Primitives" names two problems, and the first is tool results: handling
"lacks standardization, forcing developers to support multiple output formats". **SEP-2419**
(`cache_hint` well-known key in `CallToolResult._meta`) was live and updated on 2026-09-10.

## Why this server is unusually exposed to it

Its result shape was hard-won and is load-bearing:

- `content` plus `structuredContent`, with **44 operations declaring a `presentType` differing from
  `outputType`** because the presenter targets a browser;
- `bakeOnCore` prefers `Chef.bake`'s raw `dish` when the presented value has markup and no media —
  resolved **before the cache**, because a decision downstream of the cache applies to a miss and
  not a hit;
- `JSON Beautify` is why that is a correctness rule rather than a formatting one: its keys' quotes
  were markup structure, so stripping tags returned unparseable JSON.

Both directions are pinned by `tests/mcp/presented-output.test.mjs`. Any standard envelope has to
preserve that behaviour or the tests fail loudly, which is the point of having them.

## Candidate scope

- Adopt `cache_hint` on `CallToolResult` if SEP-2419 lands. The SDK fills SEP-2549's list-result
  hints from a `cacheHints` constructor option rather than from handler-returned fields — check
  whether the tool-result equivalent works the same way **before** writing any field-building code.
  v3.0.0 planned to implement cache fields the SDK already filled.
- Re-examine `src/node/lib/cache-hints.mjs`: `resources/list` and `resources/read` sit at TTL **0**
  because saved recipes change on any caller's write and no `listChanged` capability is declared.

## Trigger

SEP-2419 reaches `final`, or a result-contract SEP appears in the draft changelog.

## Kill criteria

- The SDK already implements it. **Read the SDK source, not its changelog** — that is ritual step 2,
  and v3.0.0 is the worked example of skipping it.
- The standard is advisory rather than required, and adopting it changes an output shape callers
  depend on for no measured benefit.
